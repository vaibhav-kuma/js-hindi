Detecting threats in real time requires both a responsive dashboard for analysts and a robust backend for log correlation. Most solutions are either too heavy or too disconnected. **VADT** (Threat Detection) pairs a Flask + React + MongoDB dashboard with a lightweight containerized SIEM for log ingestion, correlation, and alerting — all tagged to MITRE ATT&CK.

## Real-Time Correlation Engine

The SIEM correlates logs in real time using Kafka Streams:

```python
# Kafka Streams correlation logic
from kafka import KafkaConsumer, KafkaProducer
import json

consumer = KafkaConsumer(
    'logs.raw',
    bootstrap_servers='kafka:9092',
    value_deserializer=lambda m: json.loads(m.decode('utf-8'))
)

producer = KafkaProducer(
    bootstrap_servers='kafka:9092',
    value_serializer=lambda v: json.dumps(v).encode('utf-8')
)

RULES = load_mitre_rules()  # MITRE ATT&CK technique mappings

for message in consumer:
    log = message.value
    alerts = []
    
    for rule in RULES:
        if rule.matches(log):
            alert = {
                'technique_id': rule.technique_id,
                'technique_name': rule.name,
                'tactic': rule.tactic,
                'severity': rule.severity,
                'timestamp': log['timestamp'],
                'source_ip': log.get('source_ip'),
                'details': log
            }
            alerts.append(alert)
    
    for alert in alerts:
        producer.send('alerts.mitre', alert)
```

## Dashboard Architecture

The React dashboard consumes real-time alerts via WebSocket:

```tsx
// Real-time alert feed
function AlertFeed() {
  const [alerts, setAlerts] = useState<Alert[]>([]);
  
  useEffect(() => {
    const ws = new WebSocket('wss://api.vadt.local/ws/alerts');
    
    ws.onmessage = (event) => {
      const alert = JSON.parse(event.data);
      setAlerts(prev => [alert, ...prev].slice(0, 100));
    };
    
    return () => ws.close();
  }, []);
  
  return (
    <div className="space-y-2">
      {alerts.map(alert => (
        <AlertCard key={alert.id} alert={alert} />
      ))}
    </div>
  );
}
```

## Lessons Learned

1. **Separate concerns**: Keep SIEM correlation separate from dashboard
2. **Standardize early**: MITRE ATT&CK as the single framework for all detections
3. **Containerize everything**: Dockerized SIEM enables easy deployment and scaling
4. **Plan for volume**: Kafka handles log spikes gracefully
