Legacy system modernization is expensive, risky, and largely manual. Teams spend months reading unfamiliar code before making targeted, often error-prone changes. **legacy-lift-ai** changes this by deploying AI agents that read the code, understand the architecture, propose phased migration plans, and execute safe automated refactoring.

## Multi-Agent Architecture

The platform orchestrates multiple LLM agents with distinct responsibilities:

```typescript
// Agent orchestrator using NestJS
@Injectable()
export class AgentOrchestrator {
  constructor(
    private readonly analysisAgent: AnalysisAgent,
    private readonly mappingAgent: MappingAgent,
    private readonly riskAgent: RiskAssessmentAgent,
    private readonly transformAgent: TransformationAgent,
  ) {}

  async modernize(codebase: Codebase): Promise<ModernizationPlan> {
    const analysis = await this.analysisAgent.analyze(codebase);
    const dependencies = await this.mappingAgent.mapDependencies(analysis);
    const risks = await this.riskAgent.assess(dependencies);
    const plan = await this.transformAgent.generatePlan(risks);
    
    return plan;
  }
}
```

### Agent Responsibilities

| Agent | Role |
|-------|------|
| **Analysis Agent** | Code comprehension, pattern recognition |
| **Mapping Agent** | Dependency graph construction |
| **Risk Agent** | Migration risk scoring per module |
| **Transform Agent** | Automated refactoring with safety checks |

## Isolated Sandbox Execution

Security is paramount when processing customer code. All agents run in ephemeral, isolated sandboxes:

<Callout type="warn" title="Security First">
Source code is processed in **ephemeral, isolated sandboxes** with read-only access. No persistent storage of customer code beyond transformation artifacts.
</Callout>


## Event-Driven Communication

Agents communicate via Redis pub/sub for loose coupling and scalability:

```typescript
// Redis event bus
export class AgentEventBus {
  constructor(private readonly redis: Redis) {}

  async publish(channel: string, event: AgentEvent) {
    await this.redis.publish(channel, JSON.stringify(event));
  }

  subscribe(channel: string, handler: (event: AgentEvent) => void) {
    const subscriber = this.redis.duplicate();
    subscriber.subscribe(channel);
    subscriber.on('message', (_, message) => {
      handler(JSON.parse(message));
    });
  }
}
```
