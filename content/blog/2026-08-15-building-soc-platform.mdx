Modern security teams operate fragmented toolchains. SIEM, EDR, threat intelligence platforms, and orchestration tools all live in separate panes. Data is siloed, and analysts waste precious time stitching context together before they can respond.

**SOC_plateform** was built to solve this: a unified, AI-driven security operations platform that brings the entire security lifecycle — ingest, detect, analyze, respond — into a single React dashboard backed by 15 FastAPI microservices.

## The Architecture

The platform follows a microservices architecture orchestrated behind a Traefik API gateway:

- **Ingestion Services** — Kafka-backed log ingestion and normalization
- **Detection Engine** — MITRE ATT&CK-based threat detection and alert mapping
- **Enrichment Pipeline** — Threat intelligence correlation and scoring
- **Response Orchestrator** — Automated incident response with playbook execution
- **Dashboard** — React SPA with real-time WebSocket updates

```python
# Example: FastAPI service structure
from fastapi import FastAPI
from kafka import KafkaProducer

app = FastAPI(title="SOC Ingestion Service")

producer = KafkaProducer(
    bootstrap_servers="kafka:9092",
    value_serializer=lambda v: v.json().encode()
)

@app.post("/logs/ingest")
async def ingest_logs(logs: List[LogEntry]):
    for log in logs:
        normalized = normalize_log(log)
        await producer.send("siem.raw", normalized)
    return {"status": "accepted", "count": len(logs)}
```

## Key Engineering Decisions

| Decision | Rationale |
|----------|-----------|
| **FastAPI over Flask** | Native async support, auto-generated OpenAPI docs |
| **Kafka over RabbitMQ** | High-throughput event streaming, replay capability |
| **Microservices over monolith** | Independent deployment, scaling, team autonomy |
| **React SPA** | Real-time WebSocket updates for live alerting |
| **Elasticsearch separate from PostgreSQL** | Search/analytics isolated from operational store |

## AI Capabilities

The platform integrates several AI-driven features:

1. **Anomaly Detection Models** — Behavioral baseline deviation detection
2. **LLM-Powered Alert Summarization** — Context enrichment for analysts
3. **Automated Triage Agent** — Incident classification and routing
4. **Threat Intelligence Correlation** — Cross-reference with external feeds
